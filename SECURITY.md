# Security

Do not open a public issue that contains credentials, account identifiers or customer details.

Report a security finding through the public Vigiles contact page: https://vigileshq.com/contact

Do not attach a real state file, plan file or kubeconfig to the report.

Security fixes are published for the current release, `v1.0.0`, and for later `1.x` releases. Older tags are not maintained.

The examples use placeholder IDs and CIDR ranges. Review the account, region, quotas, service roles and network plan before you apply them.
